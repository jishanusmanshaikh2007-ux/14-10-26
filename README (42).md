# Sensor Pair Comparator

## Problem Statement
Compare two sensor values and report which one is greater or if they are equal.

## Concepts Used
- C programming
- `printf()` and `scanf()`
- Conditional statements (`if`, `else if`, `else`)

## Language
C

## Sample Input / Output
```text
Readings: 42 and 35
Output: Sensor 1 is higher.
```

## How to Run
Compile with GCC:

```bash
gcc main.c -o program
./program
```

On Windows, run:

```bash
gcc main.c -o program.exe
program.exe
```

## Note
This is a learning simulation. It accepts manually entered values and does not connect to a physical sensor.
