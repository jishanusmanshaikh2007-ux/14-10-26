# Tank Capacity Remaining

## Problem Statement
Calculate how many litres remain in a tank using capacity and current level percentage.

## Concepts Used
- C programming
- `printf()` and `scanf()`
- Conditional statements (`if`, `else if`, `else`)

## Language
C

## Sample Input / Output
```text
Capacity: 1000 L, level: 40%
Output: Empty capacity remaining: 600.00 litres
```

## How to Run
Compile with GCC:

```bash
gcc main.c -o program
./program
```

On Windows, run:

```bash
gcc main.c -o program.exe
program.exe
```

## Note
This is a learning simulation. It accepts manually entered values and does not connect to a physical sensor.
