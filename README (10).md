# Robot Heat Guard

## Problem Statement
Check a robot's simulated temperature and recommend a safe action.

## Concepts Used
- C programming
- `printf()` and `scanf()`
- Conditional statements (`if`, `else if`, `else`)

## Language
C

## Sample Input / Output
```text
Input: 82
Output: OVERHEATING: Stop robot.
```

## How to Run
Compile with GCC:

```bash
gcc main.c -o program
./program
```

On Windows, run:

```bash
gcc main.c -o program.exe
program.exe
```

## Note
This is a learning simulation. It accepts manually entered values and does not connect to a physical sensor.
