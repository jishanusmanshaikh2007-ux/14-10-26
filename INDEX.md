# 30 C Sensor and Water-Level Projects

Each folder is a separate mini-project with a unique repository-style name, `main.c`, and `README.md`.

1. **Sensor Value Inspector** — `01_sensor_value_inspector/`
   - Read a sensor value and classify it as low, normal, or high.
2. **Dual Sensor Adder** — `02_dual_sensor_adder/`
   - Read two sensor values and print their sum.
3. **Temperature Zone Classifier** — `03_temperature_zone_classifier/`
   - Classify temperature as cold, comfortable, hot, or invalid.
4. **Humidity Status Meter** — `04_humidity_status_meter/`
   - Classify relative humidity as dry, comfortable, or humid.
5. **Proximity Warning Console** — `05_proximity_warning_console/`
   - Use a simulated distance reading to decide whether an object is too close.
6. **Ambient Light Grader** — `06_ambient_light_grader/`
   - Classify a light sensor value as dark, dim, or bright.
7. **Pressure Range Guard** — `07_pressure_range_guard/`
   - Check whether a simulated pressure reading is below, within, or above a target range.
8. **Threshold Alarm Simulator** — `08_threshold_alarm_simulator/`
   - Compare a reading with a user-defined threshold and show an alert if exceeded.
9. **Sensor Pair Comparator** — `09_sensor_pair_comparator/`
   - Compare two sensor values and report which one is greater or if they are equal.
10. **Multi-Input Status Panel** — `10_multi_input_status_panel/`
   - Read temperature and humidity and print a simple status for each.
11. **Tank Fill Percentage** — `11_tank_fill_percentage/`
   - Enter a tank level percentage and display the amount category.
12. **Overflow Sentinel** — `12_overflow_sentinel/`
   - Warn when the water tank reaches its overflow warning point.
13. **Low Water Notifier** — `13_low_water_notifier/`
   - Display a shortage warning when the tank level drops below 20 percent.
14. **Pump Start Stop Simulator** — `14_pump_start_stop_simulator/`
   - Simulate a pump decision based on the water level.
15. **Tank Capacity Remaining** — `15_tank_capacity_remaining/`
   - Calculate how many litres remain in a tank using capacity and current level percentage.
16. **Water Level Safety Gate** — `16_water_level_safety_gate/`
   - Classify a tank level as too low, safe, or critical.
17. **Smart Fill Advisor** — `17_smart_fill_advisor/`
   - Recommend whether to fill, monitor, or stop filling based on tank level.
18. **Rainwater Storage Check** — `18_rainwater_storage_check/`
   - Check stored rainwater and report storage status.
19. **Water Usage Band** — `19_water_usage_band/`
   - Classify daily household water usage into low, average, or high bands.
20. **Well Level Watch** — `20_well_level_watch/`
   - Display a warning based on a simulated well water depth reading.
21. **Obstacle Distance Decider** — `21_obstacle_distance_decider/`
   - Choose STOP, SLOW, or MOVE using a simulated obstacle distance.
22. **Robot Motion Advisor** — `22_robot_motion_advisor/`
   - Recommend robot movement based on a distance sensor reading.
23. **Robot Heat Guard** — `23_robot_heat_guard/`
   - Check a robot's simulated temperature and recommend a safe action.
24. **Motor Heat Indicator** — `24_motor_heat_indicator/`
   - Classify a motor temperature as cool, warm, hot, or overheating.
25. **Battery Charge Report** — `25_battery_charge_report/`
   - Classify a simulated battery charge percentage.
26. **IR Object Presence Simulator** — `26_ir_object_presence_sim/`
   - Simulate an IR sensor result using 1 for detected and 0 for not detected.
27. **Sensor Difference Finder** — `27_sensor_difference_finder/`
   - Read two sensors and calculate the absolute difference between their values.
28. **Fire Temperature Alert** — `28_fire_temperature_alert/`
   - Simulate a fire warning based on a temperature reading.
29. **Soil Moisture Water Advisor** — `29_soil_moisture_water_advisor/`
   - Recommend whether plants need watering based on soil moisture percentage.
30. **Robot Sensor Command Center** — `30_robot_sensor_command_center/`
   - Combine distance and battery readings to make a simple simulated robot status decision.
