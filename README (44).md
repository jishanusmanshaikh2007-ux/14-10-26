# Multi-Input Status Panel

## Problem Statement
Read temperature and humidity and print a simple status for each.

## Concepts Used
- C programming
- `printf()` and `scanf()`
- Conditional statements (`if`, `else if`, `else`)

## Language
C

## Sample Input / Output
```text
Temperature: 24, humidity: 65
Output: Temperature: NORMAL; Humidity: HIGH
```

## How to Run
Compile with GCC:

```bash
gcc main.c -o program
./program
```

On Windows, run:

```bash
gcc main.c -o program.exe
program.exe
```

## Note
This is a learning simulation. It accepts manually entered values and does not connect to a physical sensor.
