# Threshold Alarm Simulator

## Problem Statement
Compare a reading with a user-defined threshold and show an alert if exceeded.

## Concepts Used
- C programming
- `printf()` and `scanf()`
- Conditional statements (`if`, `else if`, `else`)

## Language
C

## Sample Input / Output
```text
Reading: 85, limit: 80
Output: ALERT: Threshold exceeded!
```

## How to Run
Compile with GCC:

```bash
gcc main.c -o program
./program
```

On Windows, run:

```bash
gcc main.c -o program.exe
program.exe
```

## Note
This is a learning simulation. It accepts manually entered values and does not connect to a physical sensor.
