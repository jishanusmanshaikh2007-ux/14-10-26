# Robot Sensor Command Center

## Problem Statement
Combine distance and battery readings to make a simple simulated robot status decision.

## Concepts Used
- C programming
- `printf()` and `scanf()`
- Conditional statements (`if`, `else if`, `else`)

## Language
C

## Sample Input / Output
```text
Distance: 60 cm, battery: 80%
Output: STATUS: Ready to move.
```

## How to Run
Compile with GCC:

```bash
gcc main.c -o program
./program
```

On Windows, run:

```bash
gcc main.c -o program.exe
program.exe
```

## Note
This is a learning simulation. It accepts manually entered values and does not connect to a physical sensor.
