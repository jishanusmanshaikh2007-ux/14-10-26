# Smart Fill Advisor

## Problem Statement
Recommend whether to fill, monitor, or stop filling based on tank level.

## Concepts Used
- C programming
- `printf()` and `scanf()`
- Conditional statements (`if`, `else if`, `else`)

## Language
C

## Sample Input / Output
```text
Input: 95
Output: ADVICE: Stop filling.
```

## How to Run
Compile with GCC:

```bash
gcc main.c -o program
./program
```

On Windows, run:

```bash
gcc main.c -o program.exe
program.exe
```

## Note
This is a learning simulation. It accepts manually entered values and does not connect to a physical sensor.
