# Tank Fill Percentage

## Problem Statement
Enter a tank level percentage and display the amount category.

## Concepts Used
- C programming
- `printf()` and `scanf()`
- Conditional statements (`if`, `else if`, `else`)

## Language
C

## Sample Input / Output
```text
Input: 60
Output: Tank is partly filled.
```

## How to Run
Compile with GCC:

```bash
gcc main.c -o program
./program
```

On Windows, run:

```bash
gcc main.c -o program.exe
program.exe
```

## Note
This is a learning simulation. It accepts manually entered values and does not connect to a physical sensor.
